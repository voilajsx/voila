## Getting Started

### Prerequisites

- Node.js 18+ 
- npm 9+

### Development

1. Start the development server:
   ```bash
   npm run dev:api
   ```

2. The API will be available at `http://localhost:3000/api/helloworld`

### Testing

Run unit tests:
```bash
npm run test unit:run helloworld
```

Run API tests:
```bash
npm run test api:run helloworld
```

Run all tests:
```bash
npm run test all helloworld
```
