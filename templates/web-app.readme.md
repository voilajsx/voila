## 🚀 Quick Start

### Development
```bash
# Start development server
npm run server dev:web

# Generate new feature
npm run generate app:web {{APP_NAME}}/myfeature

# Run validation
npm run validate app:web {{APP_NAME}}

# Run unit tests
npm run test app:web {{APP_NAME}} -- --unittest

# Run E2E tests
npm run test app:web {{APP_NAME}} -- --e2e
```

### Adding Features

1. Generate feature scaffold:
   ```bash
   npm run generate app:web {{APP_NAME}}/myfeature
   ```

2. Define contract in `myfeature.index.ts`:
   - Routes and pages
   - Provided hooks
   - Validation level
   - SEO specifications

3. Implement types in `types/myfeature.d.ts`:
   - Component props interfaces
   - API response types
   - State management types

4. Create pages in `pages/`:
   - `root.tsx` for main page
   - Dynamic routes as needed

5. Build hooks in `hooks/`:
   - Custom logic and API integration
   - State management
   - Side effects
